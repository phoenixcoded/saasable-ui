## Getting Started

1. **Clone the repository**
	```sh
	git clone https://github.com/phoenixcoded/saasable-ui.git
	```

2. **Navigate to the Tailwind UI Kit directory**
	```sh
	cd uikit/tailwind
	```

3. **Install dependencies**
	```sh
	npm install
	```

4. **Run the project**
	```sh
	gulp
	```

5. **Open the local server URL shown in your terminal to view the app.**

## Why SaasAble?

SaasAble is a modern, responsive, and highly customizable UI kit built with Tailwind CSS. It gives you a clean, utility-first foundation with ready-to-use components, helping you build consistent and polished interfaces faster.

Designed with performance and scalability in mind, it keeps things lightweight while still offering the flexibility to adapt to different types of projects. With regular updates and a developer-friendly structure, SaasAble helps you save time and focus on building great user experiences.
